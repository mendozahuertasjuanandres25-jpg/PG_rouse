# PG_rouse

Repositorio de trabajos prácticos de programación, organizados por tecnología para facilitar su consulta y mantenimiento.

## Estructura del repositorio

```text
PG_rouse/
├── html/        # Ejercicios y proyectos en HTML
├── css/         # Hojas de estilo y prácticas en CSS
├── java/        # Ejercicios y proyectos en Java
└── javascript/  # Ejercicios y proyectos en JavaScript
```

## Organización

Cada carpeta contiene los trabajos relacionados con la tecnología indicada. Esta estructura permite localizar rápidamente los archivos y mantener los ejercicios agrupados por lenguaje o herramienta.
