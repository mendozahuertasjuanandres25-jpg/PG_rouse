# SENA | Formación para el futuro

> Introducción a tecnologías de programación y desarrollo web.

Este proyecto presenta al **Servicio Nacional de Aprendizaje (SENA)** y ofrece una guía inicial para conocer tecnologías que ayudan a desarrollar habilidades digitales y ampliar oportunidades académicas y profesionales.

## Acerca del proyecto

Esta página reúne información introductoria sobre herramientas y lenguajes utilizados en programación y creación de sitios web. Está dirigida a personas que desean iniciar o reforzar su aprendizaje tecnológico.

## Tecnologías incluidas

| Tecnología | Descripción |
| --- | --- |
| **Java** | Desarrollo de aplicaciones y fortalecimiento de la lógica de programación. |
| **HTML** | Organización y estructura del contenido de páginas web. |
| **CSS** | Diseño visual y presentación de páginas web. |
| **C++** | Fundamentos de programación y desarrollo de programas. |

## Enfoque de aprendizaje

Se propone aprender de forma progresiva: explorar los conceptos de cada tecnología, ponerlos en práctica y consolidar los conocimientos mediante proyectos.

## Propósito

Promover el aprendizaje continuo y el desarrollo de habilidades tecnológicas útiles para el crecimiento personal, académico y profesional.
